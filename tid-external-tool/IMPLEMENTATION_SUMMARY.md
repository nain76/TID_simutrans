## 使用方法

### 基本的な使い方

```bash
# 1. 依存パッケージをインストール
pip install -r requirements.txt

# 2. オフセット設定を作成
python offset_discovery.py
# → config/offsets.json を編集

# 3. Simutransを起動

# 4. TiDサーバーを起動
python tid_main.py

# 5. ブラウザでアクセス
# http://localhost:8080
```

### コマンドラインオプション

```bash
# ポート変更
python tid_main.py --port 9000

# プロセス名指定
python tid_main.py --process simutrans

# 更新間隔変更
python tid_main.py --interval 3

# カスタム設定ファイル
python tid_main.py --config my_config.json --offsets my_offsets.json
```

## トラブルシューティング

### よくある問題

1. **プロセスが見つからない**
   - Simutransが起動しているか確認
   - プロセス名を確認（Linuxでは拡張子なし）

2. **権限エラー**
   - Windows: 管理者権限で実行
   - Linux: sudo で実行

3. **データが表示されない**
   - オフセット設定を確認
   - 正しいバージョン用の設定を使用

4. **外部PCからアクセスできない**
   - ファイアウォールでポート開放
   - `host` が `0.0.0.0` になっているか確認
